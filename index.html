Iris

A voice assistant that runs on your Windows PC.

Open apps, take notes, set timers, and search the web with a spoken command. Whisper handles speech recognition; Qwen interprets requests locally.

Iris maps requests to a limited set of actions. Speech and language processing stay on the computer; web searches still need an internet connection.
